# 🌿 Plant Disease Detection using CNN & Transfer Learning

## 📌 Project Overview
This project detects plant diseases from leaf images using Deep Learning and Transfer Learning.

The model is built using TensorFlow/Keras and MobileNetV2. A Streamlit web application is used to upload leaf images and display disease predictions.

## 🚀 Features
- Upload plant leaf images
- Detect plant disease
- Display predicted disease
- Show prediction confidence
- Simple Streamlit web interface

## 🛠️ Technologies Used
- Python
- TensorFlow / Keras
- MobileNetV2
- NumPy
- Pillow
- Streamlit

## 📂 Project Structure

Plant_Disease_Project/
- Dataset/
- plant_disease_model.keras
- app.py
- requirements.txt
- README.md

## ▶️ Run the Project

Install dependencies:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app.py
